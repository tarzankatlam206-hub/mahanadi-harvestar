# महानदी हार्वेस्टर मालिक कल्याण संघ - App v2.0

## विशेषताएं
- कस्टम पासवर्ड बनाएं (मास्टर कोड: 122202678489)
- पासवर्ड हिंट के साथ लॉगिन
- 6 मॉड्यूल:
  1. सदस्य (Members) - नाम, गांव, मोबाइल, ट्रैक्टर नंबर
  2. किसान (Farmers) - खेत, फसल, एकड़
  3. ऑपरेटर (Operators) - ड्राइवर, लाइसेंस, अनुभव
  4. एजेंट (Agents) - कमीशन, क्षेत्र
  5. डीलर (Dealers) - पार्ट्स दुकान, शहर
  6. पार्ट्स (Parts) - स्टॉक, कीमत
- AsyncStorage से डेटा सेव
- सर्च, कॉल, WhatsApp डायरेक्ट
- ऑफलाइन काम करता है

## इंस्टॉल
```bash
npm install
npx expo start
```

## APK बनाएं
```bash
eas build -p android --profile preview
```
